Part2_SIMD software folder

- Part2_16x16_conf1 is for the first configuration which computes the 4 bit act 4 bit weight case. This generates the txt files in txt_conf_one which is used to test the 4 bit act 4 bit weight case. You will need to import the python files from the model_part2 file to train the VGGNet with the 8x8 convolutional layer in the VGGNet's 27th index of features. The model trained in this notebook is the one which has 8x8 for its input channels x output channels. The model is called VGG16_quant_8x8 in the models VGG_quant folder.

- Part2_16x16_conf0 is the VGG16_Quantization_Aware_Training notebook. It is used to generate the txt files in txt_conf_zero used for testing the tiled convolutional layer with 16x16 convolutional layer in the VGGNet's 27th index of features. You will need to import the python files from the model_part2 file to train the VGGNet version with the 16x16 convolutional layer. For configuration 0, the output channels were tiled into two tiles to compute the first 8 and the last 8 output channels which you will see displayed when you run the simulation. This model was trained using 2-bit quantization, and the parameter for activation quantization should already be set to 2 in the models folder. Remember, you will train the VGG16_quant_16x16 model in the models VGG_quant folder.
